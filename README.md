# Book Scraper

A Python-based web scraping application that extracts book titles, prices, and availability information from [Books to Scrape](https://books.toscrape.com/).

## Overview

Book Scraper is a simple web scraping project built with Python. It collects book information from an online bookstore and extracts useful data using Requests, BeautifulSoup, and Regular Expressions.

## Features

- Extract book titles
- Collect book prices
- Retrieve book availability information
- Parse HTML content using BeautifulSoup
- Extract structured data using Regular Expressions
- Automate data collection from web pages

## Technologies Used

- Python
- Requests
- BeautifulSoup4
- Regular Expressions (Regex)
- HTML Parsing

## Installation

**1. Clone the repository**

```bash
git clone https://github.com/sorforaj99tech/book_scraper.git
cd book_scraper
```

**2. Create a virtual environment**

```bash
python -m venv env
```

**3. Activate the virtual environment**

Windows:

```bash
env\Scripts\activate
```

**4. Install dependencies**

```bash
pip install -r requirements.txt
```

**5. Run the project**

```bash
python main.py
```
